# TicTacToeAI
TicTacToeAITic-Tac-Toe with AI

A cross-platform Tic-Tac-Toe game with artificial intelligence opponent using the Minimax algorithm with alpha-beta pruning.
🎮 Features
    Smart AI Opponent: Play against an AI that uses the Minimax algorithm for optimal gameplay
    3 Difficulty Levels:
        Easy: Random moves
        Medium: Mix of optimal and random moves
        Hard: Perfect play (unbeatable)
    Score Tracking: Keeps track of wins, losses, and draws
    Material Design 3: Modern and beautiful user interface
    Cross-Platform: Works on Windows, Linux, and Android

🚀 How It Works

The game uses the Minimax algorithm with alpha-beta pruning to calculate the best possible move for the AI player. This makes the AI nearly unbeatable on "Hard" difficulty.
Game Rules
    Player plays as X (blue)
    Computer plays as O (red)
    First to get 3 in a row (horizontally, vertically, or diagonally) wins
    If all 9 squares are filled with no winner, the game is a draw
